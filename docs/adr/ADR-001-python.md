# ADR-001: Uso de Python

## Estado
Aceptada.

## Contexto
Se necesita implementar un experimento de Machine Learning que sea sencillo de ejecutar y reproducir.

## Alternativas
- Python con scikit-learn.
- R con bibliotecas de clasificación.
- Implementación manual del algoritmo.

## Decisión
Utilizar Python, pandas y scikit-learn.

## Justificación
Permite preparar los datos, entrenar modelos, calcular métricas y ejecutar pruebas con una estructura de código sencilla.
